# ── Per-challenge checker host-deps ───────────────────────────────────
# Challenges that run their checker / flag-handler host-side (the faust-* set:
# treasury, cartography, birthdaygram, fittyfit, jokes, chat_app, marscasino)
# now carry their OWN requirements.txt inside the challenge-warehouse submodule,
# at challenge-warehouse/<contributor>/<challenge>/requirements.txt. Install only
# the ones you actually deploy, e.g.:
#   pip install -r challenge-warehouse/3rdn4Li/treasury/requirements.txt
# Without a challenge's deps it's skipped at registry discovery (logged warning).
#
# nclib is the exception that belongs here: the 1chig0 socket challenges (rceaas,
# btx, eight_bit_oracle) `import nclib` at MODULE LOAD in their
# functionality_test/_client, so registry DISCOVERY imports it on every box — a
# missing nclib skips those challenges everywhere and crashes the round loop for a
# deployed one (game_mgr round-loop). Pinned to the version already on the fleet.
nclib==1.0.8
